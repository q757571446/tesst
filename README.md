## 第一部分：有理数的定义

什么是有理数？

让我们从基础概念开始

### 有理数的定义

#### 📖 有理数的定义

**有理数是可以表示为两个整数之比的数**

即：$\\frac{p}{q}$ 的形式，其中 $p、q$ 是整数，且 $q \\neq 0$

**换句话说：**

有理数包括所有整数和分数（小数）

### 有理数的范围

\-3 \-2 \-1 0 1 2 3 有理数在数轴上的分布

有理数可以在数轴上找到对应的点

### 有理数的例子

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| 正整数 | 1, 2, 3, ... | 大于0的整数 |
| 负整数 | \-1, -2, -3, ... | 小于0的整数 |
| 零 | 0 | 既不正也不负 |
| 正分数 | $\\frac{1}{2}, \\frac{3}{4}, 0.5$ | 大于0的分数或小数 |
| 负分数 | $-\\frac{1}{2}, -0.5$ | 小于0的分数或小数 |

## 第三部分：有理数的性质

有理数有什么重要的性质？

### 有理数的基本性质

#### 性质1：相反数

如果两个数的和为0，则这两个数互为相反数

例如：3 和 -3，$\\frac{1}{2}$ 和 $-\\frac{1}{2}$

#### 性质2：倒数

如果两个数的乘积为1，则这两个数互为倒数

例如：3 和 $\\frac{1}{3}$，$-2$ 和 $-\\frac{1}{2}$

#### 性质3：绝对值

有理数的绝对值是该数与0的距离，总是非负的

例如：|3| = 3，|-3| = 3，|0| = 0

### 相反数详解

\-3 0 3 距离=3 距离=3 \-3 和 3 关于原点对称，互为相反数

设 a 是一个有理数，则 a 和 -a 互为相反数  
**a + (-a) = 0**

### 倒数详解

设 a 是一个非零有理数，则 a 和 $\\frac{1}{a}$ 互为倒数  
**$a \\times \\frac{1}{a} = 1$**

**倒数的例子：**

• 2 的倒数是 $\\frac{1}{2}$（或 0.5），因为 $2 \\times \\frac{1}{2} = 1$

• -3 的倒数是 $-\\frac{1}{3}$，因为 $(-3) \\times (-\\frac{1}{3}) = 1$

• $\\frac{2}{5}$ 的倒数是 $\\frac{5}{2}$，因为 $\\frac{2}{5} \\times \\frac{5}{2} = 1$

注意：0没有倒数（因为不能作为除数）

### 绝对值详解

有理数 a 的绝对值 |a| 定义为：  
**|a| = $\\begin{cases} a, & a \\geq 0 \\\\ -a, & a < 0 \\end{cases}$**

**绝对值的性质：**

• |a| ≥ 0（绝对值总是非负的）

• |a| = |-a|（相反数的绝对值相等）

• |ab| = |a| × |b|（乘积的绝对值等于绝对值的乘积）

• 例子：|5| = 5，|-5| = 5，|0| = 0，|0.5| = 0.5

## 第四部分：有理数的运算

学习有理数的加、减、乘、除运算

### 有理数的加法

**加法规则：**  
1\. 同号两数相加：取相同的符号，绝对值相加  
2\. 异号两数相加：取绝对值较大的数的符号，用绝对值相减  
3\. 互为相反数的两数相加为0

**加法运算例子：**

(1) 3 + 2 = **5**  
(2) (-3) + (-2) = **\-5**  
(3) 3 + (-2) = **1**  
(4) (-3) + 5 = **2**  
(5) 5 + (-5) = **0**

### 有理数的减法

**减法规则：**  
减去一个数等于加上这个数的相反数  
**a - b = a + (-b)**

**减法运算例子：**

(1) 3 - 2 = 3 + (-2) = **1**  
(2) 3 - (-2) = 3 + 2 = **5**  
(3) (-3) - 2 = (-3) + (-2) = **\-5**  
(4) (-3) - (-2) = (-3) + 2 = **\-1**

### 有理数的乘法

**乘法规则：**  
1\. 两个正数相乘，结果为正  
2\. 两个负数相乘，结果为正  
3\. 正数与负数相乘，结果为负  
4\. 任何数与0相乘，结果为0

**乘法运算例子：**

(1) 3 × 2 = **6**  
(2) (-3) × (-2) = **6**  
(3) 3 × (-2) = **\-6**  
(4) (-3) × 2 = **\-6**  
(5) 5 × 0 = **0**

### 有理数的除法

**除法规则：**  
除以一个数等于乘以这个数的倒数  
**$a \\div b = a \\times \\frac{1}{b}$（b ≠ 0）**  
除法的符号规则与乘法相同

**除法运算例子：**

(1) 6 ÷ 2 = **3**  
(2) (-6) ÷ (-2) = **3**  
(3) 6 ÷ (-2) = **\-3**  
(4) $\\frac{1}{3} \\div \\frac{1}{2} = \\frac{1}{3} \\times 2 = **\\frac{2}{3}**$

注意：除数不能为0！

### 四则运算的优先级

#### 运算顺序：

**括号 > 乘除 > 加减**

**例子：计算 2 + 3 × (-4) ÷ 2 - 5**

\= 2 + (-12) ÷ 2 - 5（先做乘法：3 × (-4) = -12）  
\= 2 + (-6) - 5（再做除法：(-12) ÷ 2 = -6）  
\= -4 - 5（从左到右做加减）  
\= **\-9**

### 有理数运算的运算律

#### 加法交换律

a + b = b + a

#### 加法结合律

(a + b) + c = a + (b + c)

#### 乘法交换律

a × b = b × a

#### 乘法结合律

(a × b) × c = a × (b × c)

#### 乘法分配律

a × (b + c) = a × b + a × c

## 第五部分：有理数的应用

有理数在生活中的应用

### 应用实例一：温度计

#### 📌 问题：

今天最高温度是5°C，最低温度是-3°C。求温度差。

#### 💡 解答：

温度差 = 最高温度 - 最低温度  
\= 5 - (-3)  
\= 5 + 3  
\= **8°C**

### 应用实例二：盈利与亏损

#### 📌 问题：

某店铺第一周的利润为3000元，第二周亏损1500元，第三周利润为2500元。求三周的总利润。

#### 💡 解答：

总利润 = 3000 + (-1500) + 2500  
\= (3000 + 2500) - 1500  
\= 5500 - 1500  
\= **4000元**

### 应用实例三：高度与深度

#### 📌 问题：

一架飞机高度为8000米，下方一潜艇深度为600米。求飞机与潜艇的距离。

#### 💡 解答：

设海平面为0，飞机高度 = 8000米，潜艇高度 = -600米  
距离 = 8000 - (-600)  
\= 8000 + 600  
\= **8600米**

### 应用实例四：存款与取款

#### 📌 问题：

小明银行账户原有2000元，第一次存入500元，第二次取出300元，第三次取出600元。求最终账户余额。

#### 💡 解答：

余额 = 2000 + 500 - 300 - 600  
\= 2000 + 500 - (300 + 600)  
\= 2500 - 900  
\= **1600元**

### 应用实例五：生产增减

#### 📌 问题：

一个工厂计划完成100件产品。第一周完成120件（超额20件），第二周完成80件（低于计划20件）。求两周共超额或低于计划多少件。

#### 💡 解答：

第一周超额：+20件  
第二周不足：-20件  
总计 = 20 + (-20)  
\= **0件**（正好完成计划）
