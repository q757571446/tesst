# Judy 的微课堂

非谓语动词：主动形式

课程目标

-   掌握 **Doing** vs **Having done** 的时间逻辑。
-   理解 **To do** 表目的与 **To be doing** 表进行的区别。

### Judy 的逻辑金句

doing: 逻辑主语发出动作。常表示伴随状态。

having done: 强调该动作发生在主句谓语动作**之前**。

to do: 常表示目的或将来的动作。

to be doing: 用于特定结构（如 pretend）中，强调动作此刻**正在进行**。
